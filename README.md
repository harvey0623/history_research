# 歷史研究知識庫總目錄索引 (Historical Research Knowledge Base Index)

本索引為「歷史研究專案」的全局導覽地圖。本知識庫以**結構史學**與**制度演化**為核心視角，透過雙向連結建立跨朝代、跨領域的立體歷史脈絡。

## 一、 核心專題與跨朝代導讀 (Thematic & Cross-Dynasty Guides)

如果你希望從「問題意識」與「制度邏輯」切入，建議優先閱讀以下跨領域核心專題：

1. **極權體制與帝國結構性困局**
   - [專制與結構性困局](./通史/專制與結構性困局.md) — 剖析地理環境、社會複雜度閹割與「繁榮—僵化—崩潰—重啟」的歷史死循環。
   - [三權分立](./明朝/制度/三權分立.md) · [內閣制](./明朝/制度/內閣制.md) · [言官](./明朝/制度/言官.md) · [中旨](./明朝/制度/中旨.md) — 明代皇權、相權（票擬）、宦官（批紅）與言官監察的動態博弈。
   - [徐高張海關係研究](./明朝/人物/文臣/徐高張海關係研究.md) — 嘉隆萬轉型期「道德、實幹與權力」的三角衝突。

2. **中國歷代兵制演化與軍閥難題**
   - [府兵募兵衛所比較](./明朝/制度/軍事/府兵募兵衛所比較.md) — 解析「財政成本、軍事戰力、中央控制力」的不可能三角。
   - [軍閥問題比較](./明朝/制度/軍事/軍閥問題比較.md) · [狄青](./宋朝/人物/武將/狄青.md) — 歷代中央與地方武力的失衡、制衡與北宋「重文輕武」體制對名將的政治清洗。
   - 歷代兵制節點：[均田制](./唐朝/制度/均田制.md) 與 [府兵制](./唐朝/制度/府兵制.md)（唐） ➔ [籓鎮節度使](./唐朝/制度/籓鎮節度使.md) 與 [魏博牙兵](./唐朝/制度/魏博牙兵.md)（唐末五代） ➔ [衛所制](./明朝/制度/軍事/衛所制.md) 與 [三大營](./明朝/制度/軍事/三大營.md) / [團營制](./明朝/制度/軍事/團營制.md)（明） ➔ [兵勇卒丁](./清朝/制度/兵勇卒丁.md)（清）。

3. **財政稅收、土地兼併與經濟改革**
   - [明初建國經濟體制](./明朝/經濟/明初建國經濟體制.md) — 洪武時期防禦性、靜態定額的「黃冊」與「魚鱗圖冊」體系。
   - [張居正經濟改革](./明朝/經濟/張居正經濟改革.md) — 考成法、清丈土地與「一條鞭法」的現代化財政轉型與人亡政息。
   - 專項財經制度：[戶籍制度](./明朝/制度/戶籍制度.md) · [屯田制](./明朝/制度/屯田制.md) · [開中法](./明朝/制度/開中法.md) · [宗室制度](./明朝/制度/宗室制度.md) · [海禁制度](./明朝/制度/海禁制度.md) · [礦稅](./明朝/制度/礦稅.md)。

4. **皇權安全、宗藩與宮廷政治**
   - [推恩令](./漢朝/制度/推恩令.md) 與 [七國之亂](./漢朝/事件/七國之亂.md)（漢代削藩） vs. [靖難之役](./明朝/事件/朱棣永樂時期/靖難之役.md) 與 [宗室制度](./明朝/制度/宗室制度.md)（明代藩王問題）。
   - [外戚](./通史/外戚.md) · [明清宮鬥比較](./明朝/制度/明清宮鬥比較.md) · [清朝宮鬥](./清朝/制度/宮鬥.md)。
