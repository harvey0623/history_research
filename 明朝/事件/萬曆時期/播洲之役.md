# 播洲之役

## 事件背景

1599年（明萬曆二十七年）至1600年（明萬曆二十八年），大明帝國西南邊陲爆發了「播洲之役」（即播州之役）。這場戰役雖與[寧夏之役](./寧夏之役.md)及[朝鮮戰爭](./朝鮮戰爭.md)並稱為「萬曆三大征」，被傳統史官視為明廷壓制地方叛亂的軍事勝利，但從大戰略視角審視，此役實則是帝國走向衰落的「勝利悲劇」。播洲楊氏自唐末起割據播州（今貴州遵義）達725年，播洲之役的爆發與終結，標誌著中央集權與地方土司世襲自治體系之間的總決算，更徹底撕裂了帝國的財政與邊防平衡。

### 1. 中央集權與世襲土司自治的結構性衝突

明初設立土司制度，本意在於「以夷制夷」，許其世襲自治。然而演變至萬曆時期，文官集團受法家大一統思想驅使，視世襲土司為「僭越之賊」。播州地處川黔要衝，富含朝廷與王府修造所需的高級建築木材、硃砂與各類礦產，文官集團與地方官僚對播州自然資源的覬覦，成為推動動武的深層經濟動機。

### 2. 跨省官僚傾軋與行政利益爭奪

播州在行政劃分上原屬四川，但地位於川黔交界。貴州省境貧瘠，財政收入匱乏，貴州巡撫（如葉夢雄、郭子張）極度渴望將富庶的播州劃歸貴州管轄，以提升地方政績與稅收來源。這種川黔兩省[巡撫總督](../../制度/巡撫總督.md)之間的利益爭奪與行政傾軋，極大激化了朝廷在處置播州事務時的強硬態度。

### 3. 土司內部生態崩潰與世族孤立

播州宣慰使楊應龍性格殘暴，因寵幸小妾田雌鳳，悍然殺害具備朝廷「誥命夫人」身份的正妻張氏。此舉徹底激怒了播州權力結構的核心——「五司七姓」（田、張、元、羅、吳等世襲大族）。地方豪強轉而與明廷流官聯手彈劾，使楊應龍在播州內部的世襲自治網絡中陷入孤立無援的境地。

### 4. 官吏極限逼反與人質死局

楊應龍起初並無叛逆之意，甚至在1592年（明萬曆二十年）主動提出率領苗兵赴朝鮮參加[朝鮮戰爭](./朝鮮戰爭.md)抗擊日軍。然而，四川巡撫王繼光強硬緝拿，並將其次子楊可棟作為人質押解至重慶獄中折磨致死。官府事後更扣押屍首、勒索鉅額罰金，徹底切斷了和平解決的政治路徑。加之貴州巡撫江東之故意派少量官兵送死以製造開戰藉口，配合小冰河期帶來的極端氣候與邊疆貿易受阻，逼使楊應龍採取「以掠奪養兵」的絕路。

| 衝突維度     | 明廷／文官集團視角                                       | 播州楊氏／土司視角                   |
| :----------- | :------------------------------------------------------- | :----------------------------------- |
| **政治定位** | 視土司為朝廷叛逆與「僭越之賊」                           | 依託725年世襲合法性維持區域自治      |
| **經濟利益** | 覬覦播州的建築木材、硃砂與礦產資源                       | 抵制官僚剝削，維繫在地資源自主       |
| **行政動機** | 川黔兩省爭奪稅收與[巡撫總督](../../制度/巡撫總督.md)政績 | 抗拒逼反與人質勒索（楊可棟之死）     |
| **戰略結果** | 強推「改土歸流」，消滅世襲土司                           | 楊氏自焚滅亡，在地自組織政治生態破壞 |

## 發展歷程

### 1. 叛亂擴大與綦江血案：1599年（明萬曆二十七年）

- **綦江失陷與朝野震動**：1599年（明萬曆二十七年），楊應龍率數萬苗兵破綦江，屠殺明軍與平民，直接威脅成都與重慶。兵報傳至京師，萬曆帝震怒，將播州叛亂提升為國家一級軍事危機。
- **總督掛帥**：明廷緊急啟用經略李化龍總督四川、湖廣、貴州軍務，統籌平叛全局。

### 2. 八路合圍與天險攻堅：1600年（明萬曆二十八年）

萬曆二十八年（1600年）二月，李化龍調集遼東鐵騎、浙江步兵、兩廣狼兵等全國精銳共24萬大軍，採取「八路合圍、分道並進」的立體戰術。明廷同時啟用抗倭名將劉綎（劉大刀）、吳廣、馬孔英等率軍進擊。

| 戰爭維度     | 明軍優勢                             | 播州天險挑戰                         | 戰略後果                                   |
| :----------- | :----------------------------------- | :----------------------------------- | :----------------------------------------- |
| **兵力規模** | 24萬絕對優勢，李化龍統籌八路合擊。   | 楊氏依託山川設外圍九關層層阻擊。     | 導致帝國財政體系出現「終端破裂」。         |
| **將領素質** | 啟用劉綎（劉大刀）、吳廣等抗倭名將。 | 播州蠻兵善山地伏擊（如白石口大戰）。 | 遼東精銳南下，造成東北防線長達半年的真空。 |
| **技術攻堅** | 調集大砲與鳥銃，火力遠超土司武裝。   | 海龍屯海拔1300米，純石質結構天險。   | 物理抹殺楊氏宗族，終結725年世襲統治。      |
| **防禦體系** | 國家機器不計代價的持續投入。         | 內置水井農田，具備長期圍城條件。     | 確立了戰後「改土歸流」的強硬基調。         |

### 3. 海龍屯決戰與楊氏覆滅

海龍屯海拔1300米，純石質結構，內置水井與農田，為山地堡壘天險。明軍經歷144天的慘烈攻堅戰，逐一突破海龍屯外圍與內部防線：

- **攻克前六關**：明軍冒著弩箭與巨石，憑藉優勢火砲與密集兵力，先後拔除銅柱、鐵柱、飛虎（三十六級天梯）、飛龍、朝天、飛鳳六關。
- **突破後三關**：1600年（明萬曆二十八年）六月初六，劉綎與吳廣先後攻破土城、石城、萬安關後三關，明軍湧入屯頂。
- **楊氏自焚**：楊應龍見大勢已去，身穿宣慰司華麗朝服與寵妾田雌鳳於屯內自焚身亡。割據播州725年的楊氏世襲政權在物理上被完全抹殺。

## 影響與意義

### 1. 國庫枯竭與財政連鎖崩潰

播洲之役軍費耗資達300萬至700萬兩白銀。連同[寧夏之役](./寧夏之役.md)（耗銀200萬兩）與[朝鮮戰爭](./朝鮮戰爭.md)（耗銀780萬兩），「萬曆三大征」總軍費超過1300萬兩，徹底耗竭了[張居正](../../人物/文臣/張居正.md)改革以來積累的國庫剩餘。
為彌補黑洞，萬曆帝廣派[礦稅](../../制度/礦稅.md)監與稅使橫行全國（如[雲南礦稅案](./雲南礦稅案.md)），加派全國賦稅高達四成，致使富戶慘減七成以上。這種極限掠奪直接誘發了1629年（明崇禎二年）高迎祥、李自成、張獻忠等農民起義的爆發。

### 2. 東北防線真空與滿洲趁勢崛起

為平定播州，明廷從遼東抽調大量軍事精銳與名將（如劉綎），造成東北防線長達半年的戰略真空。努爾哈赤利用這一窗口期迅速統一女真各部、積蓄實力。後在1619年（明萬曆四十七年）[薩爾滸之戰](./薩爾滸之戰.md)中，曾平定播州的名將劉綎戰死沙場，明朝在東北戰場陷入全面被動。

### 3. 西南地緣震盪與「奢安之亂」

播洲之役消滅了楊氏，使水西土司安氏因助戰獲地而實力大增。二十年後（1621年，明天啟元年），明廷為應對東北危機再次強徵西南土司兵北上，誘發了持續17年、波及川黔滇三省的「奢安之亂」。其中貴陽圍城戰導致城內40萬人口僅存200餘人，西南半壁生靈塗炭，皆為播州地緣震盪的延續。

### 4. 改土歸流與地方文明生態退化

戰後明廷將播州一分為二：遵義府劃歸四川，平越府劃歸貴州，強行推行「改土歸流」。然而，新建的「無根流官體制」僵化腐敗，摧毀了在地原有的有機自組織政治生態，使原本商貿繁榮、文化發達的播州退化為死氣沉沉的平庸郡縣。

| 播洲之役短期戰果               | 長期戰略負資產與副作用                                                       |
| :----------------------------- | :--------------------------------------------------------------------------- |
| 物理抹殺播州楊氏，消滅土司割據 | 東北防線空虛，給予努爾哈赤崛起契機                                           |
| 行政劃分遵義、平越二府         | 引發「奢安之亂」，導致西南府庫空虛與數十萬平民慘死                           |
| 擴張中央集權，強推「改土歸流」 | 「無根流官體制」導致地方政治生態退化與經濟萎縮                               |
| 展現國家機器對山地防線攻堅能力 | 耗盡國庫剩餘，逼迫朝廷加徵[礦稅](../../制度/礦稅.md)與田賦，埋下明末起義伏筆 |

## 研究結論

播洲之役在戰術執行層面無疑是一場極其成功的山地圍殲戰與天險攻堅戰，但在大戰略層面卻是一場「自掘墳墓」的體制性失敗。官僚體系為了追求微小的行政增量與政治政績，不惜強逼土司走向絕路，並透支帝國生存根基。

海龍屯的火光，不僅燃盡了割據七百年的播洲楊氏，也燒毀了大明帝國在西南的防禦屏障與財政底氣，成為推動明朝加速走向覆滅的致命轉折點。
