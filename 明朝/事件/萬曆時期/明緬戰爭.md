# 明緬戰爭

## 事件背景

明緬戰爭（又稱萬曆抗緬之役）是爆發於明朝中後期（嘉靖至萬曆年間），明朝與緬甸東吁王朝為爭奪西南邊疆控制權與朝貢宗主地位而展開的一場長期地緣軍事衝突。這場戰役不僅深刻重塑了西南邊陲的土司版圖，更標誌著明代西南羈縻體系的瓦解與邊防戰略的重大收縮。

### 1. 明代西南邊疆的「三宣六慰」羈縻體系

自明初[沐英](../../人物/武將/沐英.md)經略雲南以來，明廷在雲南南部與西南邊境廣泛推行世襲土司制度，確立了「三宣六慰」的外圍羈縻體系：

- **三宣撫司**：南甸宣撫司、干崖宣撫司、隴川宣撫司。
- **六宣慰司**：車里宣慰司、緬甸宣慰司、木邦宣慰司、八百大甸宣慰司、孟養宣慰司、老撾宣慰司。
- **治理侷限**：明廷採取「以夷制夷」的間接統治，並未派遣流官常駐，亦無常設正規軍駐防。土司內部常因宗族繼承權、土地與人口產生激烈械鬥，邊防結構高度依賴中央王朝的軍事威懾，具備嚴重的脆弱性與易崩性。

| 體系層級             | 代表機構                 | 統治方式                           | 軍事防禦特徵                           |
| :------------------- | :----------------------- | :--------------------------------- | :------------------------------------- |
| **內層邊疆（三宣）** | 南甸、干崖、隴川         | 朝廷冊封世襲宣撫使，部分受流官節制 | 距離雲南腹地較近，設有關隘與哨所       |
| **外層邊疆（六慰）** | 孟養、木邦、車里、緬甸等 | 頒賜印信，定期朝貢，高度內部自治   | 無正規軍駐紮，依賴土司武裝「以夷制夷」 |

### 2. 緬甸東吁王朝的崛起與北擴

16世紀中葉，緬甸東吁王朝在第三代君主**莽應龍**統治時期迅速崛起，統一緬甸中南部，成為中南半島強大的擴張型軍事政權：

- **蠶食外圍土司**：莽應龍在位期間積極北擴，利用明朝對西南邊務的漠視，先後吞併了八百大甸、老撾、車里等宣慰司。
- **明廷的消極應對**：明嘉靖至隆慶年間，雲南地方官僚普遍奉行「多一事不如少一事」的消極避戰方針，對前來求援的忠明土司（如孟養土司思箇）採取「緊閉關隘、嚴禁出援」的孤立政策，導致西南藩籬門戶大開。

### 3. 內外勾結的導火線：岳鳳之叛

1581年（明萬曆九年），莽應龍病逝，其子**莽應里**繼位，延續大規模侵略擴張路線。此時隴川土司內部發生嚴重叛亂，直接點燃了全面大戰：

- **岳鳳引狼入室**：江西撫州籍亡命商人**岳鳳**贅入隴川宣撫司，後為篡奪統治權，毒殺宣撫同知多士寧，割地投靠緬甸東吁王朝。
- **緬軍深入腹地**：岳鳳充當嚮導並獻出邊防要圖，引導緬甸象騎與步兵數萬人長驅直入，接連攻陷隴川、孟密、威遠、干崖，並直逼姚關與保山，震動雲南全省與北京朝廷。

## 發展歷程

### 1. 戰略反擊與威震西南：1583年－1584年（明萬曆十一年至十二年）

面對緬軍的全面進逼，明廷於1583年（明萬曆十一年）任命劉天浧巡撫雲南，緊急起用兩大抗倭名將**劉綎**與**鄧子龍**入滇主持軍務：

- **姚關大捷與攀枝花設伏**：緬軍主力猛攻姚關，副總兵鄧子龍率部急馳增援。鄧子龍利用攀枝花隘口的險要地形設下重伏，採取火器突襲與兩翼截擊戰術，大破緬軍戰象陣與步兵主力，斬首數千級。
- **隴川光復與生擒岳鳳**：參將劉綎（號稱「劉大刀」）率領精銳長驅直入，分兵合圍隴川。1584年（明萬曆十二年），明軍攻破岳鳳老巢，生擒叛首岳鳳及其子岳曩烏，押解京師磔死。
- **傳檄威定諸司**：劉綎進一步率軍深入阿瓦（緬甸舊都）以北地區，招撫孟養、木邦、孟密諸土司，一度重建了明廷在滇緬邊陲的軍事權威。

```
【萬曆初期反擊路線】
姚關遭圍 ──> 鄧子龍「攀枝花伏擊戰」大破緬軍 ──> 劉綎馳援隴川 ──> 生擒岳鳳父子 ──> 威撫孟養、木邦諸司
```

### 2. 將領調離與戰局反覆：1585年－1592年（明萬曆十三年至二十年）

- **文武傾軋與名將去職**：隨後劉綎與鄧子龍因朝廷派系黨爭及雲南文官彈劾，相繼被調離西南邊防。
- **緬軍重整旗鼓**：莽應里趁明軍主力撤離與統帥更迭之際，再度發動大規模反撲，反覆圍攻木邦、孟密與孟養。
- **土司陣營分化**：由於明廷無法提供持續性的兵力庇護，邊境土司陷入分裂與搖擺，部分土司被迫向緬甸稱臣納貢。

### 3. 戰略收縮與修築「騰越八關」：1593年－1600年（明萬曆二十一年至二十八年）

1593年（明萬曆二十一年），雲南巡撫**陳用賓**針對緬軍頻繁入寇且明軍補給線過長的困境，提出「轉攻為守、以關定界」的收縮防禦方略：

- **騰越八關構築**：陳用賓在騰越（今雲南騰衝）西南沿線的交通天險處修建了八座軍事防禦關隘，統稱**騰越八關**（神護關、萬仞關、巨石關、銅壁關、鐵壁關、虎踞關、天馬關、漢龍關），並派遣兵勇實行常態化屯守。
- **防禦重心內縮**：騰越八關的設立在戰術上成功構築了屏障雲南腹地的內層防線，但在戰略層面上，實質上標誌著明廷放棄了對八關以外廣大宣慰司（關外數千里土地）的實質保護與統治。

### 4. 戰事終局與孟養陷落：1600年－1606年（明萬曆二十八年至三十四年）

- **東吁內訌與阿瓦割據**：萬曆二十八年後，緬甸東吁王朝因連年對外擴張（與暹羅阿瑜陀耶王國作戰）及內部叛亂而陷入分裂，阿瓦政權崛起。
- **最後屏障瓦解**：1606年（明萬曆三十四年），緬軍傾全力猛攻長期效忠明朝的孟養土司。孟養土司思洪向明廷告急求援，但此時明廷正全力應對[播洲之役](./播洲之役.md)後的西南震盪與遼東戰略局勢，無力發兵。最終思洪孤軍戰死，孟養徹底淪陷。明緬長達數十年的軍事衝突至此走向沉寂。

## 影響與意義

### 1. 地緣政治版圖重塑與疆界定型

- **三宣六慰瓦解**：明代自永樂以來經營兩百餘年的西南外圍羈縻藩籬徹底瓦解，孟養、木邦、孟密、八百大甸、老撾等廣闊區域實質脫離明朝版圖，併入緬甸勢力範圍。
- **中緬邊界格局雛形**：陳用賓所設「騰越八關」劃定了明清兩代在西南實際管轄的西界，客觀上奠定了清代乃至近代中緬邊界走向的歷史底色。

### 2. 邊防戰略與治理模式的體制反思

- **羈縻體系的不可持續性**：明緬戰爭暴露出「只封不管、以夷制夷」政策在面對中央集權化擴張政權時的致命缺陷。缺乏正規軍駐守與財政自給能力的土司網絡，極易在外部軍事重壓下分化瓦解。
- **由經略外藩轉向關隘固守**：明廷從早期的跨區域外向型經略，徹底退縮至依託地形的內向型防禦，加速了中央集權在邊疆治理中的「改土歸流」政策轉向。

### 3. 多線作戰的戰略透支

明緬戰爭與同時期的[寧夏之役](./寧夏之役.md)、[朝鮮戰爭](./朝鮮戰爭.md)、[播洲之役](./播洲之役.md)在時間上高度交織。名將劉綎、鄧子龍在西南作戰積累了極高軍事威望，但隨後轉戰朝鮮與遼東（鄧子龍於1598年露梁海戰殉國，劉綎於1619年[薩爾滸之戰](./薩爾滸之戰.md)殉國）。頻繁的多線調兵與軍費開銷，進一步加劇了晚明財政與軍事精銳的透支。

## 研究結論

明緬戰爭是晚明邊疆史上的關鍵轉折點。從戰役戰術層面而言，鄧子龍的攀枝花大捷與劉綎的深入追剿，展現了明軍在將領得力與戰術靈活情況下的強大野戰與攻堅能力，成功粉碎了東吁王朝直接吞併雲南腹地的野心；然而從大戰略與地緣治理層面審視，受制於國家財政儲備枯竭、官僚朋黨傾軋與東北女真邊患的牽制，明廷無法維持對滇西南外圍長達數千里的長期軍事承諾。

「騰越八關」的設立是一次務實卻代價沉重的地緣妥協——它保全了雲南核心腹地的安全，卻以犧牲「三宣六慰」外圍藩籬為代價，宣告了明帝國在東南亞北部地緣擴張期的徹底終結。
