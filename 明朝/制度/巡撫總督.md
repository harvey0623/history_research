# 巡撫與總督

## 歷史背景

明朝初年，地方權力架構實行承宣布政使司（管民政與財政）、提刑按察使司（管司法與監察）與都指揮使司（管軍事衛所）「三司分立」架構。三司互不統屬，各自向中央對應部門負責。此設計初衷是為了防止地方官員專權與藩鎮割據，但到了明朝中期，面對日益複雜的社會危機，三司體制在應對以下兩大麻煩時面臨嚴重阻礙：

1. **內部危機（衛所破產）**：隨著[衛所制](./軍事/衛所制.md)崩潰，地方武官腐敗，士兵大量逃亡，都指揮使司已無力管轄與整頓地方兵備。
2. **外部危機（邊防與變亂）**：北方遊牧民族（如瓦剌、韃靼）頻繁寇邊，南方盜匪與倭寇亦四處作亂。這種跨省份、跨區域的大規模戰爭，因地方三司互不統屬、事權分散，難以形成高效指揮鏈，在協調軍隊、調配物資及統籌指揮上極其低效。

為打破三司互不統屬的行政壁壘，解決文武脫節與跨省協調問題，明廷自中葉起發展出一套**「差遣制度」**（非九品常官，係奉特旨出鎮之欽差），派遣高級文臣作為中央特派員進駐地方，確立了**「文臣統兵，節制武將」**的軍政指揮體系。

其職權等級與節制次序為：
$$\text{經略} \succ \text{總督} \succ \text{巡撫} \succ \text{總兵}$$

巡撫與總督作為地方督撫體系的中樞，上承戰時最高統帥「經略」，下轄第一線實戰統兵的「總兵」，並與負責京畿治安的府尹共同構成明代中後期的立體化統治網絡。

## 現代組織概念比喻

為了更直觀理解督撫差遣體系與傳統行政職官的運作邏輯，可以現代跨國企業的組織架構進行對照：

| 職稱     | 現代跨國企業/集團對應角色         | 角色特質與職責                                         |
| :------- | :-------------------------------- | :----------------------------------------------------- |
| **經略** | **特派危機處理總監 / 專案總指揮** | 極高層特派，跨大戰區最高專斷裁決權，戰事結束即解編。   |
| **總督** | **大區營運總裁（Regional CEO）**  | 統管跨省/多個戰區的戰略協調、糧餉調撥與部隊調度。      |
| **巡撫** | **分公司總經理兼營運長**          | 一省或單一軍鎮最高軍政長官，負責內政、稅賦與防務組織。 |
| **總兵** | **一線作戰處處長（專業武將）**    | 純軍事作戰指揮官，手握兵馬但必須受文官戰略節制。       |
| **府尹** | **總部直轄市市長（首都市長）**    | 專管京畿首善之區行政、戶籍、司法與治安，層級低於督撫。 |

## 核心內容摘要

### 1. 經略（戰區最高統帥、非常設救火隊長）

- **性質與官銜**：多稱「經略軍務」或「經略安撫使」，為戰時臨時特設之最高文臣差遣。
- **品銜與授權**：多由**兵部尚書**或兼**都察院左/右都御史**出任（位列從一品或正二品）。常賜尚方寶劍，具臨機專斷處決之權。
- **管轄職責**：僅在國家爆發極端重大戰略危機（如萬曆援朝、遼東戰局）時特派。統管跨數省乃至跨國戰區，全面節制戰區內所有總督、巡撫、提督與總兵。戰事結束後即予撤銷。
- **代表人物**：
  - **宋應昌**：萬曆年間[朝鮮戰爭](../事件/萬曆時期/朝鮮戰爭.md)任經略，統籌軍務糧餉，節制提督李如松。
  - **熊廷弼、孫承宗**：明末遼東經略，經略遼東軍務。

### 2. 總督（大軍區跨省統帥、協調樞紐）

- **性質與官銜**：多為「總督某處軍務兼理糧餉」（如薊遼總督、宣大總督、三邊總督、兩廣總督），為跨行政區文官差遣，明中葉後逐漸制度化、常態化。
- **品銜與授權**：多由**兵部尚書或兵部侍郎**兼**都察院右都御史或右僉都御史**出任（正二品至正三品銜）。位階高於巡撫，在軍政事務上具節制轄區內各省巡撫之權。
- **管轄**：兩省以上或特定軍事邊防區域（跨越數省或數個軍事重鎮）。
- **經典防區**：
  - **陝西三邊總督**：專責總督陝西延綏、寧夏、甘肅三邊軍務，統領西北防線。
  - **薊遼總督**：專責統轄薊州、昌平、遼東、保定四處重鎮的防禦，管轄疆域極廣，統領邊防衛所與數省巡撫。
  - **宣大總督**：統管宣府、大同、山西三鎮軍務糧餉。
- **職責**：
  - **軍事統籌**：最核心任務，負責跨省區大規模戰事戰略部署、軍馬兵額調配、防線構築與剿匪平叛。
  - **協調樞紐**：統籌跨省軍餉督運與部隊調度，直接指揮轄區內的巡撫與各鎮總兵。
- **代表人物**：
  - **[胡宗憲](../人物/文臣/胡宗憲.md)**：總督直浙等處軍務，統籌東南沿海抗倭。
  - **王守仁（王陽明）**：總督兩廣軍務兼巡撫，平定叛亂。
  - **袁崇煥、洪承疇**：明末薊遼總督。

### 3. 巡撫（省級軍政一把手、封疆大吏）

- **性質與官銜**：多為「巡撫某處地方贊理/兼理軍務」。原為中央都察院派遣巡視地方之臨時御史（「巡視撫綏」），景泰、成化以後演變為常設之一省軍政最高首長。
- **品銜與授權**：多以**都察院右副都御史**或**右僉都御史**充任，常加兼**兵部侍郎**銜（正三品至從二品銜）。居於地方三司之上。
- **管轄**：原則上管轄**一省**或邊疆單一軍鎮（如山東巡撫、遼東巡撫、廣東巡撫、偏沅巡撫）。
- **職責**：
  - **行政與財政**：全面統籌省內民政、水利、稅收與民生。
  - **司法監察**：監督地方審案、清理刑獄與維護行政法治。
  - **軍事整飭（核心）**：負責一省內的「整飭兵備」。在[衛所制](./軍事/衛所制.md)崩潰後，轉而利用地方財政在本地推行[募兵制](./軍事/府兵募兵衛所比較.md)、籌措糧餉、整編地方軍防，戰時負責本省兵員動員與後勤供應，並配合總督防務。
- **代表人物**：
  - **于謙**：曾巡撫河南、山西，以清廉勤政整肅民生著稱。
  - **王化貞**：明末廣寧巡撫。

### 4. 總兵 / 總兵官（前線武將指揮核心）

- **性質與官銜**：全稱「鎮守某處總兵官」，為四大軍政差遣中**唯一的純武職差遣**。
- **品銜與授權**：多由公、侯、伯等軍功勳貴或**左/右都督、都督同知**（正一品、從一品武階）充任。出征時佩帶專屬**將軍印**（如遼東總兵佩「平遼將軍印」、宣府總兵佩「鎮朔將軍印」）。
- **管轄職責**：專司前線實戰指揮、部隊操練與要塞防禦。無民政與財政權，兵員後勤糧餉仰賴巡撫與戶部調撥。在「文臣統兵」體系確立後，在戰略上受制於經略、總督與巡撫文官。
- **代表人物**：
  - **[戚繼光](../人物/武將/戚繼光.md)**：薊鎮總兵，創立鴛鴦陣、主持邊防整軍。
  - **李成梁、李如松**：遼東總兵。
  - **吳三桂**：山海關總兵。

### 5. 京師特例：順天府與應天府（府尹）

除督撫外，明朝在「京師」地區設有特殊的府級行政機構，其地位高於一般地方府，直接隸屬中央。

- **應天府（南京）**：明初洪武時期首都政府，永樂遷都後保留為留都機構，管理南京及周邊地區。
- **順天府（北京）**：1421年（明永樂十九年）遷都後之首都政府，管理北京及周邊地區。
- **職位：府尹**
  - **性質**：首都市長，負責首都地區的戶籍、稅收、治安與司法。
  - **地位**：雖為首都官，但管轄範圍僅限於「府」級（一城及其屬縣），在行政與軍事統屬層級上低於巡撫與總督。

## 發展脈絡：從臨時差遣到制度化

### 巡撫制度的確立

- **萌芽期（15世紀初，明宣宗時期，約1420年代）**：最初稱為「巡撫某地等處地方」，屬中央派遣之臨時性使節，任務在於安撫流民、清查貪墨與賑濟災傷。
- **常設化（15世紀中期，明英宗之後）**：面對頻繁的社會流民與財政赤字問題，中央改為長期派駐巡撫，並加銜都察院與兵部，使其逐漸凌駕於布政使之上，演變為實際的省級軍政首長。

### 總督制度的演進

- **起源（15世紀中後期，明英宗時期）**：因應邊境蒙古入侵（如1449年明正統十四年[土木堡之變](../事件/英宗危機與復辟/土木堡之變.md)）或南方民族叛亂，臨時設立跨省軍事指揮官以統一調度。
- **常設化（16世紀，明中後期）**：隨著北方邊防壓力（「北虜」）與東南「倭患」常態化，區域性的總督（如宣大、三邊、薊遼、兩廣）轉為長期設立，成為跨行政區的最高軍事與戰略統合樞紐。

### 經略與總兵的制度演變

- **總兵官之常態化**：明初總兵官多在戰時由開國公侯充任，佩將軍印出征，事畢繳印；永樂以後隨九邊防禦體系成形，總兵官逐漸轉化為常設鎮守之武職大將，但兵權受制於巡撫與總督。
- **經略之戰時特設**：萬曆以降，明帝國面臨萬曆三大征及遼東女真崛起等極端戰事，一般總督已不足以統籌跨多省乃至跨國（如援朝）軍情，遂特派經略以專斷軍務，位居文臣督撫體系的最頂端。

## 歷史影響與意義

1. **權力集中與垂直管理**：
   - 巡撫打破了地方三司分立各自為政的僵局，總督則解決了跨省巡撫在戰時無法有效協同的困境。兩者均直接對皇帝負責，強化了中央對地方軍政事務的垂直管控。
2. **「以文御武」體制的成效與代價**：
   - **正面體制成效**：地方總督與巡撫通常由中央的兵部尚書/侍郎或都察院都御史兼任，以中央高級文臣身份領兵。這成功防範了世襲武將擁兵自重，避免了中晚唐五代「藩鎮割據」局面的重演。文官統籌財政與軍政，亦有利於集中調度全國物力以應對重大危機。
   - **負面體制弊端（以文御武過甚）**：督撫多為儒生出身，部分文臣缺乏前線戰術素養，武將失去臨機機動的主導權，動輒得咎。戰時文臣與監軍太監層層干涉，導致部隊戰鬥力與戰略主動性受損。
3. **職權重疊與「經撫不和」的制度死結**：
   - 當經略、總督與巡撫同駐一地或職權範圍重疊時，極易因戰略分歧生發嚴重的權力傾軋與指揮混亂。
   - **典型教訓**：1622年（明天啟二年）**廣寧之戰**，遼東經略熊廷弼主張防守待變，廣寧巡撫王化貞主張主動出擊。王化貞手握重兵躁進輕敵，熊廷弼居後無兵難以實質節制，「經撫不和」最終釀成廣寧潰敗、全遼防線盡失，成為晚明軍政指揮鏈崩潰的標誌性悲劇。
4. **配合「募兵制」延續國祚**：
   - 當[衛所制](./軍事/衛所制.md)在中後期崩潰、兵力虛弱時，正是依靠各地的督撫利用手上的行政與財政大權，在地方招募職業雇傭軍並籌措軍餉。
   - 著名的「戚家軍」即是在總督[胡宗憲](../人物/文臣/胡宗憲.md)與巡撫的大力支持和軍餉保障下，由總兵[戚繼光](../人物/武將/戚繼光.md)編練成軍，成為抗倭防虜的精銳。
5. **「分權防叛」與「集權勝戰」的制度矛盾**：
   - 明太祖朱元璋為防造反，刻意將地方拆分為三司互不隸屬；但後世為追求戰爭指揮效率，不得不透過增設督撫與經略將權力重新收歸文臣。這深刻反映出中國傳統帝制中「分權防內亂」與「集權防外患」難以兩全的體制困境。
6. **京師府的特殊性**：府尹制度確保了中央對首都地區的直接掌控，但在司法與治安上與巡撫、巡按御史亦存在一定程度的事權交疊。

## 研究結論

明代巡撫與總督制度的形成與演進，體現了中國古代中央集權官僚體系「先臨時差遣，後制度化常設」的動態調整規律。面對衛所制瓦解與內外軍事危機，明廷透過發展「經略—總督—巡撫—總兵」的四級差遣指揮鏈，打破了明初地方三司分立的事權壁壘，確立了「以文御武」的治理格局。

此一制度成功防範了地方軍閥割據，並使國家在財政困窘之際得以統籌物力編練募兵；然而其先天的權責重疊弊端、經撫不和的內耗，以及文臣對武將實戰指揮的過度干預，亦在晚明危機中被無限放大，成為影響明帝國軍事走向的雙刃劍。

## 參考資料
